《广东爱情故事》— AI 黑客松 中期检查提交说明

一、作品概况

  • 作品名称：广东爱情故事（Guangdong Love Story）
  • 作品类型：网页互动视觉小说（Visual Novel），纯前端单文件实现
  • 一句话简介：2010 年广东一座小城里，打工青年阿榕与病中女孩小满相爱相扛的故事；一场重病、一笔手术费，照见爱情与现实的拉扯。含双结局（好 / 坏）与分支选择。
  • 运行环境：任意现代浏览器（Chrome / Edge / Firefox / Safari），无需联网、无需安装、无需服务器。

二、当前进度（中期 · 2026-10-24）

  • ✅ 完整主线剧情：序章 → 第一至七章 → 间幕 → 双结局 → 尾声采访 → 祠堂终章（共 7 章 + 序幕 + 3 段间幕 + 结局分支）。
  • ✅ 角色立绘系统：9 张角色立绘（阿榕、小满、周谨医生、许闻记者、珍姐、老六、护士、早餐摊阿姨、黑色剪影），含半写实灰调统一画风。
  • ✅ 场景美术：17 张实景风格背景（出租屋、街道、诊所、工厂、医院三景、殡仪馆、祠堂四景、生日病房、深夜手术走廊、医生办公室等），均与剧情节点一一对应。
  • ✅ 交互系统：鼠标点击推进对话、左上「‹ 回退」回溯对话（跨不过选择点与章节）、右上「音·开/关」开关、分支选择、两个小游戏（打螺丝 / 整理单据）。
  • ✅ 音频：背景音乐（DarkPiano 钢琴曲，循环）+ 4 类合成音效（点击对话 / 选择 / 打螺丝 / 整理单据）。
  • ✅ 经济与结局联动：高消费（老火汤 / 蛋糕）次数超阈值 → 手术费缺口 → 强制坏结局；未超消费时按概率判定（由常量 BAD_RATE 控制，当前 0.70 → 坏结局 70% / 好结局 30%，坏比好高 40 个百分点），让故事基调偏向"现实压过爱情"的悲剧底色。坏结局尾声措辞已与好结局区分（避免"他们"指代不明）。

三、如何运行 / 提交评审

提供两种等价交付物，任选其一即可：

1. 【推荐 · 单文件】广东爱情故事_提交版.html

  • 已把全部立绘、场景、标题纸、背景音乐以 base64 内联进这一个 HTML。
  • 任何情况下（双击、file:// 打开、微信/网盘传输、放进任何目录）都不会出现"图片显示不出来"的问题。
  • 双击即可在浏览器运行，无需联网，无需附带任何文件夹。

2. 【工程版】index.html + scenes/ + portraits/ + audio/ + assets/

  • 若需查看/二次开发源码，请用此版本；必须保持文件夹结构完整，否则立绘与场景路径会失效。

> 评审只需拿到上面任意一个文件/文件夹就能完整体验，不会出现立绘或场景空白。

四、玩法 / 交互说明（给评审速览）

  • 进入标题页 → 点「开始」即进入序章。
  • 点击屏幕任意处：逐句播放对话；点击左上「‹ 回退」可回看上一句（选择点与上一章之间无法跨回，保证剧情逻辑）。
  • 分支选择：剧情中出现选项时，点按钮做出选择，影响金钱、好感与结局走向。
  • 小游戏：第六章葬礼"低语聆听"、第七章手术室外"等待"等节点含轻交互小游戏。
  • 音效开关：右下「音·开/关」控制背景音乐与音效（默认关，点开即有钢琴 BGM + 交互音效）。

五、技术栈

  • 纯前端，单文件 HTML + 原生 JavaScript + 内联 SVG / CSS，无框架、无构建步骤、无第三方运行时。
  • 所有美术资源以本地图片 / 内联 Data-URI 形式存在，零外部网络依赖。
  • 音频使用 WebAudio 实时合成音效 + 一段授权钢琴曲（已内联）。
